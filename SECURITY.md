# Security Policy

## Supported Versions

We actively provide security updates for the following versions of **Frutiger.js**:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

The Frutiger.js team takes security vulnerabilities seriously. If you believe you have found a security issue in `@frutiger-js/core` or `@frutiger-js/react`, please do **NOT** open a public issue on GitHub.

Instead, please send an email directly to:

📧 **[biagio.scaglia@gmail.com](mailto:biagio.scaglia@gmail.com)**

Please include:

1. A description of the vulnerability and its potential impact.
2. Steps to reproduce the issue or a minimal proof-of-concept repository.
3. Any proposed mitigations or fixes, if available.

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours.
- **Vulnerability Assessment**: Within 5 business days.
- **Fix & Coordinated Disclosure**: As soon as a patch is tested and published.

Thank you for responsibly disclosing security issues to protect our community.
